# 简历项目描述（三段式）

## 项目概述

面向 Severstal 钢材表面缺陷数据，构建 Apple Silicon/macOS 可运行的四类多标签语义分割工程；采用原图级冻结数据划分，完成数据审计、RLE/Mask 解码、滑窗整图评估及可复现训练/推理链路。

## 方法与工程

实现从头初始化的 ResNet18 U-Net 与 BCE 基线，并完成 BCE+Soft Dice、类别感知采样两组受控对照；建立完整 checkpoint 恢复、MPS 训练、类别级 Dice/IoU/Precision/Recall、正常图误检统计及错误可视化。最终冻结 E0 Epoch 24，导出四通道 raw-logit ONNX，并提供单图/目录批量推理。

## 结果与交付

基于固定阈值 0.50 与正常图 FPR 约 34.01% 的验证约束选择最终候选；ONNX 在合成及冻结验证样本上与 PyTorch 的阈值 Mask 一致率为 100%，并完成独立 1,895 张测试图的一次性评估。交付包含模型/manifest 哈希、依赖快照、性能与错误分析报告、推理脚本和测试案例；测试指标未用于调参。
